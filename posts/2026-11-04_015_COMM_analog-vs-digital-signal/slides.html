Definition · Тодорхойлолт
ANALOG · 아날로그 · АНАЛОГ
값이 끊김 없이 이어지는 연속 신호. 범위 안의 어떤 값이든 가질 수 있음
A continuous signal that can take any value in a range.
Тодорхой мужид ямар ч утга авч болох тасралтгүй дохио.
DIGITAL · 디지털 · ДИЖИТАЛ
정해진 몇 개의 값만 갖는 이산 신호. 대표적으로 0과 1
A discrete signal with only a limited set of values, like 0 and 1.
Зөвхөн цөөн тогтсон утгатай (0 ба 1) салангид дохио.
아날로그 = 연속 · 디지털 = 이산(불연속)
Analog is continuous · Digital is discrete

아날로그 → 디지털 (PCM)
Analog to digital in Python · Python-оор хөрвүүлэх
import math
fs, L = 8, 8   # 8번 표본화, 3비트=8단계
for n in range(fs):
    x = math.sin(2*math.pi*n/fs)  # ① 표본화
    q = round((x+1)/2*(L-1))      # ② 양자화
    print(n, q, f"{q:03b}")       # ③ 부호화
# 0 4 100 / 1 6 110 / 2 7 111 ...
① 표본화: 시간을 일정 간격으로 끊어 값을 읽음
EN: Sampling · MN: Түүвэрлэлт — тогтмол хугацаанд утга авна
② 양자화: 읽은 값을 정해진 단계로 반올림
EN: Quantization · MN: Квантчлал — тогтсон түвшинд дугуйлна
③ 부호화: 단계 번호를 2진수(0·1)로
EN: Encoding · MN: Кодчилол — хоёртын тоо болгоно

Check points · Анхаарах зүйлс
01  잡음에 강한 디지털 · Noise
디지털도 잡음은 생기지만 0/1만 구분하면 원래대로 복원
Дижитал дохиог 0/1-ээр ялгаад сэргээхэд амар
02  나이퀴스트 정리 · Nyquist
표본화 주파수 ≥ 최고 주파수 × 2 (CD: 44.1kHz)
Түүвэрлэх давтамж ≥ хамгийн их давтамж × 2
03  양자화 오차 · Quantization Error
비트 수를 늘리면 작아지지만 0은 아님
Бит нэмбэл алдаа багасна, гэхдээ 0 болохгүй
04  데이터 ≠ 신호 · Data vs Signal
디지털 데이터도 아날로그 신호로 전송 가능 (모뎀)
Дижитал өгөгдлийг аналог дохиогоор дамжуулж болно
