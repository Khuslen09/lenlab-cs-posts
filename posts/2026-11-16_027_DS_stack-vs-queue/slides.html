Python으로 비교해 보기
Compare in Python · Python дээр харьцуулах
from collections import deque

stack = []
for x in [1, 2, 3]: stack.append(x)  # push
print(stack.pop())      # 3

queue = deque()
for x in [1, 2, 3]: queue.append(x)  # enqueue
print(queue.popleft())  # 1
① 같은 1, 2, 3을 넣어도 스택은 3, 큐는 1이 먼저
EN: Same input, different order · MN: Ижил оролт, өөр дараалал
② 스택은 list의 append·pop으로 충분
EN: A list works as a stack · MN: list-ийг стек болгон ашиглана
③ 큐는 deque의 popleft() → O(1)
EN: Use deque for queues · MN: Дараалалд deque ашигла
