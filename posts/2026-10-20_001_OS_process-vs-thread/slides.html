Java로 스레드 만들기
Creating threads in Java · Java-д урсгал үүсгэх
Runnable task = () ->
  System.out.println(
    Thread.currentThread().getName());

Thread t1 = new Thread(task, "chef-1");
Thread t2 = new Thread(task, "chef-2");
t1.start();  // run() 아님 · not run()
t2.start();
① JVM 프로세스 1개 안에서 스레드 3개(main + chef-1 + chef-2)가 동시에 실행
EN: One process, three threads at once · MN: Нэг процесст 3 урсгал зэрэг ажиллана
② start()는 새 스레드 생성, run()은 그냥 메서드 호출
EN: start() makes a new thread · MN: start() шинэ урсгал үүсгэнэ
③ 출력 순서는 실행할 때마다 달라질 수 있음
