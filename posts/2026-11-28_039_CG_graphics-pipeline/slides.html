GLSL 셰이더 두 개
Two GLSL shaders · Хоёр GLSL шейдер
// ① vertex shader — 정점마다
uniform mat4 MVP;
in vec3 aPos;
void main() {
  gl_Position = MVP * vec4(aPos, 1.0); }
// ④ fragment shader — 프래그먼트마다
out vec4 FragColor;
void main() {
  FragColor = vec4(0.0, 0.8, 1.0, 1.0); }
① MVP 행렬로 정점 좌표 변환
EN: MVP matrix transforms each vertex · MN: MVP матрицаар оройг хувиргана
② 프래그먼트 셰이더는 칸마다 색(RGBA)을 출력
EN: Outputs a color per fragment · MN: Фрагмент бүрийн өнгийг гаргана
③ 그 사이 래스터화는 GPU가 고정 기능으로 처리
EN: Rasterization is fixed-function · MN: Растержуулалт тогтмол функц
