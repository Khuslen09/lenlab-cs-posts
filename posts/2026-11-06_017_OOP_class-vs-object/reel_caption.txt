🇰🇷 클래스 vs 객체, 붕어빵으로 끝! 🐟
클래스 = 붕어빵 틀(설계도), 객체 = 찍어 낸 붕어빵(실체).
👉 틀은 1개, 객체는 new 할 때마다 하나씩! 변수에는 참조가 담겨요.

🇺🇸 Class vs object, explained with a fish-shaped pastry! 🐟
Class = the mold (blueprint), object = the pastry you bake (the real thing).
👉 One mold, a new object every time you call new! Variables hold references.

🇲🇳 Класс ба объект — загасан хэлбэрийн боовоор тайлбарлая! 🐟
Класс = боовны хэв (зураг төсөл), объект = хэвээр хийсэн боов (бодит зүйл).
👉 Хэв нэг, new хийх бүрт шинэ объект үүснэ! Хувьсагчид объектын лавлагаа (reference) хадгалагдана.
