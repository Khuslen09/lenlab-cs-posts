Java로 객체 만들기
Creating objects in Java · Java-д объект үүсгэх
class Car {
  String color;                 // 필드 · field
  Car(String color) { this.color = color; }
  void drive() {                // 메서드 · method
    System.out.println(color + " car drives");
  }
}
Car a = new Car("red");    // 객체 1
Car b = new Car("blue");   // 객체 2
a.drive();  // red car drives
① 클래스 Car 1개로 객체 a, b 2개를 생성
EN: One class, two objects · MN: Нэг классаас 2 объект
② new + 생성자가 객체를 만들고 필드 값을 초기화
EN: new + constructor builds it · MN: new ба конструктор үүсгэнэ
③ 같은 drive()라도 객체마다 자기 color를 사용
EN: Each uses its own color · MN: Объект бүр өөрийн color-ыг ашиглана

Check points · Анхаарах зүйлс
01  객체 vs 인스턴스 · Object vs Instance
같은 실체. Car의 인스턴스처럼 클래스와의 관계를 말할 때 인스턴스
Ижил зүйл; класстай холбоог онцлоход instance гэнэ
02  정의 ≠ 생성 · new
class만 쓰면 객체는 0개. new 해야 힙에 생성
Класс бичихэд объект үүсэхгүй, new хийхэд heap-д үүснэ
03  변수 = 참조 · Reference
변수는 객체 자체가 아니라 객체를 가리키는 참조
Хувьсагч нь объект биш, объект руу заах лавлагаа
04  static은 클래스 소속 · static
static 필드는 모든 객체가 공유하는 클래스 변수
static талбарыг бүх объект хуваалцдаг
