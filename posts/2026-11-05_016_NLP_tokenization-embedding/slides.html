TOKENIZATION · 토큰화 · ТОКЕНЧЛОЛ
문장을 모델이 다루는 작은 단위인 토큰으로 나누는 것
Splitting text into small units called tokens.
Текстийг токен гэх жижиг нэгжүүдэд хуваах.
EMBEDDING · 임베딩 · ЭМБЕДДИНГ
각 토큰을 의미를 담은 실수 벡터로 바꾸는 것
Mapping each token to a vector of real numbers that carries meaning.
Токен бүрийг утга агуулсан бодит тоон вектор болгох.
문장 → 토큰 → ID → 벡터

Try it in Python · Python дээр туршъя
import numpy as np
tokens = "i love nlp i love ai".split()
vocab = {w: i for i, w in
         enumerate(dict.fromkeys(tokens))}
ids = [vocab[t] for t in tokens]
print(ids)  # [0, 1, 2, 0, 1, 3]

E = np.random.rand(len(vocab), 3)  # 4×3 표
print(E[ids].shape)  # (6, 3)
① 같은 토큰은 언제나 같은 ID (i → 0, love → 1)
EN: Same token, same ID · MN: Ижил токен — ижил ID
② 임베딩 = 표에서 ID번째 행을 꺼내는 것
EN: Embedding is a table lookup · MN: Хүснэгтээс ID-р мөр авах
③ 처음엔 랜덤, 학습하며 의미가 담김
EN: Random at first, learned in training · MN: Эхэндээ санамсаргүй, сургалтаар утга шингэнэ

Check points · Анхаарах зүйлс
01  토큰 ≠ 단어 · Subword
요즘 모델은 단어를 더 쪼갠 서브워드(BPE 등)를 씀
Орчин үеийн загварууд үгийг дэд үг (subword) болгон хуваадаг
02  ID 숫자엔 의미 없음 · ID is just an index
ID 3이 ID 1보다 크다고 더 중요한 단어가 아님
ID бол зүгээр л дугаар, том нь илүү чухал гэсэн үг биш
03  원-핫 vs 임베딩 · One-hot vs Dense
원-핫: 길고 대부분 0 / 임베딩: 짧고 촘촘한 실수 벡터
One-hot: урт, ихэнх нь 0 · Эмбеддинг: богино, нягт вектор
04  의미가 비슷하면 가깝다 · Similarity
학습된 임베딩에서 고양이·강아지 벡터는 가까움
Сургасан эмбеддингт ойролцоо утгатай үгс ойрхон байна
