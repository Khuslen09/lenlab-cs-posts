직접 세어 보기 (Linux)
Counting switches in Python · Python-оор тоолох
import os, time
def ctx():
    with open(f"/proc/{os.getpid()}/status") as f:
        d = dict(l.split(":", 1) for l in f)
    return int(d["voluntary_ctxt_switches"])
before = ctx()
for _ in range(100):
    time.sleep(0.001)  # CPU 양보
print(ctx() - before)  # 약 100
① sleep·I/O 대기 → 스스로 CPU 양보 (voluntary)
EN: Waiting gives up the CPU · MN: Хүлээхдээ CPU-г өөрөө өгнө
② 타임 슬라이스 끝 → OS가 뺏음 (선점)
EN: Time slice ends, OS preempts · MN: Хугацаа дуусвал OS булаана
③ 전환을 결정·수행하는 건 커널(스케줄러)
EN: The kernel does the switch · MN: Шилжилтийг цөм (kernel) хийнэ
