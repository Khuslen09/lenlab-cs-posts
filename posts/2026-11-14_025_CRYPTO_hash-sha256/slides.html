Definition · Тодорхойлолт
HASH · 해시 함수 · ХЭШ ФУНКЦ
임의 길이의 입력을 고정 길이 값(해시값)으로 바꾸는 함수
Maps input of any length to a fixed-length value (digest).
Дурын оролтыг тогтмол урттай утга болгодог функц.
SHA-256 · SHA-2 계열
암호학적 해시. 출력은 항상 256비트 (16진수 64자)
A cryptographic hash; output is always 256 bits (64 hex chars).
Криптограф хэш; гаралт нь үргэлж 256 бит (16-тын 64 тэмдэгт).
해시 = 단방향 · 같은 입력 → 항상 같은 출력
One-way · Same input → always the same output

Python으로 해시 보기
SHA-256 in Python · Python-д SHA-256
import hashlib

h1 = hashlib.sha256(b"lenlab").hexdigest()
h2 = hashlib.sha256(b"Lenlab").hexdigest()
print(h1[:16])  # 0900e59a64bf7983
print(h2[:16])  # ffd8b4fbd6c4f8d2
print(len(h1))  # 64
① 한 글자만 달라도 해시가 완전히 바뀜 (눈사태 효과)
EN: Avalanche effect · MN: Нэг үсэг өөрчлөхөд хэш бүрэн өөрчлөгдөнө
② 16진수 64자 × 4비트 = 256비트
EN: 64 hex × 4 bits = 256 bits · MN: 64 тэмдэгт × 4 бит = 256 бит
③ 같은 입력 = 같은 해시 → 파일 무결성 확인
