🇰🇷 해시 함수는 왜 되돌릴 수 없을까?
⠀
해시 함수는 어떤 길이의 입력이든 고정 길이 값으로 바꾸는 단방향 함수예요.
SHA-256은 대표적인 암호학적 해시로, 결과는 항상 256비트(16진수 64자)예요.
⠀
👉 한 글자만 달라도 해시가 완전히 바뀌고, 해시는 암호화가 아니라서 키도 복호화도 없어요!
⠀

🇺🇸 Why can't a hash function be reversed?
⠀
A hash function is a one-way function that maps input of any length to a fixed-length value.
SHA-256 is a widely used cryptographic hash whose output is always 256 bits (64 hex chars).
⠀
👉 Change one character and the hash changes completely. Hashing is not encryption: no key, no decryption.
⠀

🇲🇳 Хэш функц ба SHA-256 — яагаад буцааж болдоггүй вэ?
⠀
Хэш функц бол дурын урттай оролтыг тогтмол урттай утга болгодог нэг чиглэлтэй функц.
SHA-256 бол түгээмэл криптограф хэш бөгөөд гаралт нь үргэлж 256 бит (16-тын 64 тэмдэгт).
⠀
👉 Нэг үсэг өөрчлөхөд хэш бүрэн өөрчлөгдөнө. Хэш бол шифрлэлт биш: түлхүүр ч, тайлах үйлдэл ч байхгүй.
