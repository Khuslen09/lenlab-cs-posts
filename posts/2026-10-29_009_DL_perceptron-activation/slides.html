Python으로 AND 게이트
AND gate with a perceptron · Перцептроноор AND
def AND(x1, x2):
    w1, w2, b = 0.5, 0.5, -0.7
    s = w1*x1 + w2*x2 + b   # 가중합
    return 1 if s > 0 else 0  # 계단

for x in [(0,0), (0,1), (1,0), (1,1)]:
    print(x, AND(*x))
# → 0, 0, 0, 1
① 둘 다 1일 때만 s = 0.3 > 0 → 출력 1
EN: Only (1,1) gives s > 0 · MN: Зөвхөн (1,1) үед s > 0
② 가중치·편향만 바꾸면 OR·NAND도 가능
EN: Change w, b for OR, NAND · MN: w, b-г өөрчилбөл OR, NAND
③ 학습 = 이 w와 b를 데이터로 찾는 과정
EN: Training finds w and b · MN: Сургалт нь w, b-г олох үйл явц
