한 줄 정의
Definition · Тодорхойлолт
TCP · 연결형 · ХОЛБОЛТТОЙ
연결을 맺고 보내는 프로토콜. 데이터가 빠짐없이, 순서대로 도착하도록 보장
Connection-oriented: reliable, in-order delivery.
Холболт тогтоож, өгөгдлийг алдалгүй, дарааллаар нь хүргэнэ.
UDP · 비연결형 · ХОЛБОЛТГҮЙ
연결 없이 바로 보내는 프로토콜. 보장은 없지만 가볍고 빠름
Connectionless: no guarantees, but light and fast.
Холболтгүйгээр шууд илгээнэ. Баталгаагүй ч хөнгөн, хурдан.
둘 다 전송 계층(L4) · 포트 번호로 앱을 구분
Both are transport-layer protocols that use ports

전화 = TCP · 엽서 = UDP
Phone call = TCP · Postcard = UDP
Утасны дуудлага = TCP · Ил захидал = UDP
TCP · 먼저 연결 · Connect first
A ── SYN ──────▶ B
A ◀── SYN+ACK ── B
A ── ACK ──────▶ B
A ── DATA ─────▶ B  (ACK 확인)
▲ 3-way handshake · 잃어버리면 재전송 · Resend if lost
UDP · 그냥 보냄 · Just send
A ── DATA 1 ───▶ B
A ── DATA 2 ──✕  (손실 · lost)
▲ 확인·재전송 없음 · No ACK, no resend

Python 소켓으로 보기
Sockets in Python · Python сокет
# TCP: 연결부터 맺고 보낸다
t = socket.socket(AF_INET, SOCK_STREAM)
t.connect(("127.0.0.1", 9000))
t.sendall(b"hello")

# UDP: 연결 없이 바로 보낸다
u = socket.socket(AF_INET, SOCK_DGRAM)
u.sendto(b"hello", ("127.0.0.1", 9001))
① SOCK_STREAM = TCP, SOCK_DGRAM = UDP
EN: STREAM is TCP, DGRAM is UDP · MN: STREAM = TCP, DGRAM = UDP
② connect() 순간 3-way handshake 진행
EN: connect() runs the handshake · MN: connect() үед handshake хийгдэнэ
③ 받는 쪽이 없으면 TCP는 에러, UDP는 그냥 전송
EN: No receiver: TCP fails, UDP still sends · MN: Хүлээн авагчгүй бол TCP алдаа, UDP илгээнэ

여기서 꼭 헷갈린다
Check points · Анхаарах зүйлс
01  헤더 크기 · Header Size
TCP 최소 20바이트 / UDP 고정 8바이트
TCP толгой хамгийн багадаа 20 байт, UDP 8 байт
02  스트림 vs 데이터그램 · Boundaries
TCP는 메시지 경계 없음, UDP는 보낸 단위 그대로
TCP мессежийн хил хадгалахгүй, UDP хадгална
03  어디에 쓰나 · Use Cases
TCP: 웹·메일·파일 / UDP: DNS·스트리밍·게임
TCP: веб, имэйл · UDP: DNS, стрим, тоглоом
04  HTTP/3는 UDP · QUIC
HTTP/3는 UDP 위의 QUIC에서 신뢰성을 직접 구현
HTTP/3 нь UDP дээрх QUIC-ээр ажиллана
