🇰🇷 C는 오류 하나면 실행도 안 되는데, Python은 왜 돌아갈까? 📕
컴파일 = 책 통번역, 인터프리터 = 동시통역.
👉 C는 번역 단계에서 멈추고, Python은 오류 줄에서 멈춰요!

🇺🇸 One error stops C from running — so why does Python start anyway? 📕
Compiler = translate the whole book; interpreter = live interpretation.
👉 C stops at compile time; Python stops when it reaches the bad line!

Хөрвүүлэгч = номыг бүхэлд нь орчуулах, тайлбарлагч = шууд орчуулга.
👉 C хөрвүүлэх үедээ зогсдог бол Python алдаатай мөрөнд хүрээд л зогсдог!
