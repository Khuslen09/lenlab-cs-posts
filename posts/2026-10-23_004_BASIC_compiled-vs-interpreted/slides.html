실행 전에 소스 전체를 한 번에 기계어로 번역 → 실행 파일 생성
Translates the whole source into machine code before running.

INTERPRETER · 인터프리터 · ТАЙЛБАРЛАГЧ
실행하면서 소스를 한 줄(문장)씩 번역하고 바로 실행
Translates and runs the source statement by statement.
Эх кодыг мөр мөрөөр нь хөрвүүлж, шууд ажиллуулна.
컴파일 = 먼저 번역, 빠른 실행 · 인터프리터 = 바로 실행
