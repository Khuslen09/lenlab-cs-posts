NumPy로 합성곱 직접
Convolution by hand in NumPy · NumPy-ээр конволюц
import numpy as np
img = np.array([[1,2,0,1],[0,1,3,1],
                [2,1,0,2],[1,0,1,1]])  # 4×4
k = np.array([[1,0],[0,-1]])  # 2×2 filter
out = np.zeros((3,3), int)  # (4-2)/1+1 = 3
for i in range(3):
    for j in range(3):
        out[i,j] = (img[i:i+2, j:j+2]*k).sum()
print(out)  # [[0 -1 -1] [-1 1 1] [2 0 -1]]
① 4×4 입력 + 2×2 필터 → 3×3 특징 맵
EN: 4×4 in, 2×2 filter, 3×3 out · MN: 4×4 оролт → 3×3 гаралт
② 칸마다 곱한 뒤 합계 = 가중합
EN: Each cell is a weighted sum · MN: Нүд бүр жигнэсэн нийлбэр
③ 실제 CNN은 필터 값을 학습으로 정함
EN: Real CNNs learn the filter values · MN: Шүүлтүүрийн утгыг сургалтаар олно

Check points · Анхаарах зүйлс
01  출력 크기 공식 · Output Size
입력 N, 필터 F, 패딩 P, 스트라이드 S → (N−F+2P)/S + 1
Гаралтын хэмжээ = (N−F+2P)/S + 1
02  가중치 공유 · Weight Sharing
같은 필터를 이미지 전체에 재사용 → 파라미터가 적음
Нэг шүүлтүүрийг бүх зурагт дахин ашиглана → параметр цөөн
03  풀링은 학습 X · Pooling
최대 풀링은 영역의 최댓값만 → 크기만 줄임
Max pooling зөвхөн хэмжээг багасгана, сурах параметргүй
04  사실은 교차상관 · Cross-correlation
대부분의 라이브러리는 필터를 뒤집지 않고 계산
Ихэнх сан шүүлтүүрийг эргүүлэлгүй тооцдог
