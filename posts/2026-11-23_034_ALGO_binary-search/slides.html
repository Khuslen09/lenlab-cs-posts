Implement in Python · Python дээр бичих
def binary_search(arr, target):
    lo, hi = 0, len(arr) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if arr[mid] == target: return mid
        elif arr[mid] < target: lo = mid + 1
        else: hi = mid - 1
    return -1
nums = [2, 5, 8, 12, 16, 23, 38, 56, 72, 91]
print(binary_search(nums, 23))  # 5
① lo·hi 두 포인터로 남은 범위를 표시
EN: lo and hi mark the range · MN: lo, hi нь үлдсэн мужийг заана
② 작으면 lo = mid + 1, 크면 hi = mid - 1
EN: Move one side past mid · MN: mid-ийн цаадах тал руу шилжинэ
③ 범위가 비면(lo > hi) 없음 → -1
EN: Empty range means not found · MN: Муж хоосон бол олдсонгүй
