🇰🇷 100만 개 중에서 20번 만에 찾는 법? 🎯
정렬된 배열에서 가운데와 비교 → 절반씩 버리기 = O(log n).
👉 정렬이 전제! 작으면 lo = mid + 1, 크면 hi = mid − 1, 조건은 lo <= hi.

🇺🇸 Find one item among a million in 20 tries? 🎯
Compare with the middle of a sorted array → throw away half each time = O(log n).
👉 The array must be sorted! Smaller: lo = mid + 1, bigger: hi = mid − 1, loop while lo <= hi.

🇲🇳 Сая элементээс 20 алхамд хайж олох арга? 🎯
Эрэмбэлсэн массивын дундахтай харьцуулж → хагасыг нь хаях = O(log n).
👉 Эрэмбэлэгдсэн байх ёстой! Бага бол lo = mid + 1, их бол hi = mid − 1, нөхцөл lo <= hi.
