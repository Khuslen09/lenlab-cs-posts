Python으로 보는 두 단계
Two steps in Python · Python дээрх хоёр алхам
users = {"len": {"pw": "1234", "role": "user"}}
def login(name, pw):     # 인증 AuthN
    u = users.get(name)
    return u if u and u["pw"] == pw else None
def can_delete(user):    # 인가 AuthZ
    return user["role"] == "admin"
u = login("len", "1234")
print(u is not None, can_delete(u))  # True False
① 로그인 성공 = 인증 통과 (True)
EN: Login works, identity verified · MN: Нэвтэрлээ, хэн болох нь батлагдлаа
② 그래도 role이 user라 삭제 권한 없음 (False)
EN: Still no delete permission · MN: Гэхдээ устгах эрхгүй
③ 실제로는 비밀번호를 해시로 저장 (#025)
EN: Real apps store hashed passwords · MN: Бодит системд нууц үгийг хэшээр хадгална
