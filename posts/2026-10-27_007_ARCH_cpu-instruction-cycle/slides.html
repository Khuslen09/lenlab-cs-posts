Python으로 흉내 내기
A toy CPU in Python · Python дээр жижиг CPU
mem = [("LOAD", 5), ("ADD", 3), ("HALT", 0)]
pc, acc = 0, 0
while True:
    ir = mem[pc]; pc += 1      # Fetch
    op, val = ir               # Decode
    if op == "LOAD": acc = val # Execute
    elif op == "ADD": acc += val
    elif op == "HALT": break
print(acc)  # 8
① pc는 다음에 가져올 명령어의 위치
EN: pc points to the next instruction · MN: pc дараагийн зааврыг заана
② 가져오자마자 pc += 1 → 다음 줄 준비
EN: pc moves on right after fetch · MN: Татсаны дараа pc нэмэгдэнэ
③ acc = 누산기(AC), 계산 결과를 담는 레지스터
EN: acc is the accumulator · MN: acc нь үр дүн хадгалах регистр
