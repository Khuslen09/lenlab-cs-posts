🇰🇷 CPU는 명령어를 어떻게 실행할까? ⚡
인출(Fetch) → 해독(Decode) → 실행(Execute) 무한 반복!
👉 PC = 다음 명령어의 주소, IR = 지금 실행할 명령어 자체.

🇺🇸 How does a CPU run an instruction? ⚡
Fetch → Decode → Execute, again and again!
👉 PC = address of the next instruction; IR = the current instruction itself.

🇲🇳 CPU зааврыг хэрхэн гүйцэтгэдэг вэ? ⚡
Татах (Fetch) → тайлах (Decode) → гүйцэтгэх (Execute) мөчлөг тасралтгүй давтагдана!
👉 PC = дараагийн зааврын хаяг, IR = одоо гүйцэтгэж буй заавар өөрөө.
