🇰🇷 hello.c가 실행 파일이 되기까지 4단계, 말할 수 있어?
⠀
전처리로 #include·#define을 풀고, 컴파일로 C를 어셈블리어로 번역해요.
어셈블로 기계어(.o)를 만들고, 링크로 라이브러리와 묶어 실행 파일이 돼요.
⠀
👉 전처리 → 컴파일 → 어셈블 → 링크! undefined reference는 링크 단계 에러예요.
⠀
⠀
🇺🇸 From hello.c to an executable — can you name the 4 steps?
⠀
Preprocessing expands #include and #define, then compiling turns C into assembly.
Assembling makes machine code (.o), and linking joins it with libraries into an executable.
⠀
👉 Preprocess → Compile → Assemble → Link! undefined reference is a linker error.
⠀
⠀
🇲🇳 hello.c гүйцэтгэх файл болох 4 үе шатыг хэлж чадах уу?
⠀
Урьдчилсан боловсруулалт #include, #define-ийг задалж, хөрвүүлэлт C кодыг ассемблер хэл рүү орчуулна.
Ассемблер машин код (.o) үүсгэж, холбогч (linker) түүнийг сантай нийлүүлж гүйцэтгэх файл болгоно.
⠀
👉 Урьдчилсан боловсруулалт → Хөрвүүлэлт → Ассемблердах → Холбох! undefined reference бол холбох үеийн алдаа.
