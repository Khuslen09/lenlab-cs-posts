같은 +, 다른 결과
Same +, different result · Ижил +, өөр үр дүн
age = 20
print(type(age))     # <class 'int'>

print(3 + 4)         # 7   정수 덧셈
print("3" + "4")     # 34  문자열 연결
print(int("3") + 4)  # 7   형 변환
① 연산의 의미는 자료형이 정함
EN: The type decides what + means · MN: Үйлдлийн утгыг төрөл нь тодорхойлно
② "3"은 숫자가 아니라 문자 → int()로 변환
EN: "3" is text, convert with int() · MN: "3" бол текст, int()-ээр хөрвүүлнэ
