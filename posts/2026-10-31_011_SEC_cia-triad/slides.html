해시로 무결성 확인하기
Checking integrity with a hash · Hash-аар шалгах
import hashlib

msg  = b"send 10000 won to A"
saved = hashlib.sha256(msg).hexdigest()

recv = b"send 90000 won to A"  # 변조
check = hashlib.sha256(recv).hexdigest()

print(saved == check)  # False
① 글자 하나만 바뀌어도 해시값이 완전히 달라짐
EN: One changed character, a totally different hash · MN: Ганц тэмдэгт өөрчлөгдөхөд hash бүрэн өөр болно
② 값 비교로 변조 감지 → 무결성(I) 확인
EN: Compare hashes to detect tampering · MN: Hash-ийг харьцуулж өөрчлөлтийг илрүүлнэ
③ 해시는 내용을 숨기지 않음 → 기밀성(C)과 별개
EN: A hash does not hide data · MN: Hash нь мэдээллийг нууцлахгүй
