🇰🇷 배열과 포인터, 뭐가 같고 뭐가 달라?
⠀
배열은 같은 타입 값이 메모리에 연속으로 놓인 묶음이고,
배열 이름은 식에서 쓰면 대부분 첫 원소의 주소(&arr[0])로 바뀌어요.
⠀
👉 arr[i]는 *(arr + i)와 같아요! 하지만 배열 이름은 arr++처럼 바꿀 수 없어요.
⠀
⠀
🇺🇸 Arrays and pointers — what's the same, what's different?
⠀
An array is a block of same-type values stored next to each other in memory.
In most expressions, the array name turns into the address of its first element (&arr[0]).
⠀
👉 arr[i] is the same as *(arr + i)! But you can't change the array name itself, like arr++.
⠀
⠀
🇲🇳 Массив ба заагч (pointer) — юу нь адил, юу нь өөр вэ?
⠀
Массив бол санах ойд дараалан байрласан ижил төрлийн утгуудын цуглуулга.
Ихэнх илэрхийлэлд массивын нэр эхний элементийн хаяг (&arr[0]) болж хувирна.
⠀
👉 arr[i] нь *(arr + i)-тэй адил! Гэхдээ массивын нэрийг arr++ гэж өөрчилж болохгүй.
⠀
