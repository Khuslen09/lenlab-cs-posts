C로 직접 써 보기
Try it in C · C хэл дээр туршъя
int arr[3] = {10, 20, 30};
int *p = arr;           // = &arr[0]

printf("%d\n", *(p + 1)); // 20
printf("%d\n", p[2]);     // 30
printf("%zu\n", sizeof(arr)); // 12
printf("%zu\n", sizeof(p));   // 8
p++;    // OK
// arr++;  컴파일 오류
① 포인터에도 p[2]처럼 인덱스를 쓸 수 있음

01  배열 ≠ 포인터 · Not the same
배열은 원소를 담는 공간, 포인터는 주소 하나를 담는 변수
Массив элементүүдийг хадгална, заагч нэг хаяг хадгална
02  배열 이름은 못 바꿈 · No arr++
p++는 되지만 arr++, arr = p는 오류
p++ болно, харин arr++ алдаа өгнө
03  함수에 넘기면 포인터 · Decay
f(int a[])의 a는 사실 int * → sizeof(a)는 8
