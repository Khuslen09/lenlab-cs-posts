int a[4] = {1, 2, 3, 4};
int *p = a + 1;
*(p + 2)의 값은?
What is *(p + 2)?
③ 4
정답 · ANSWER · ХАРИУЛТ
p는 a[1]을 가리키니까
*(p + 2) = a[3] = 4
p points to a[1], so *(p + 2) is a[3], which is 4.
p нь a[1]-ийг заадаг тул *(p + 2) = a[3] = 4.
