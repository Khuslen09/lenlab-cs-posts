Definition · Тодорхойлолт
POINTER · 포인터 · ЗААГЧ
값 대신 다른 변수의 메모리 주소를 저장하는 변수
A variable that stores the memory address of another variable.
Өөр хувьсагчийн санах ойн хаягийг хадгалдаг хувьсагч.
& ADDRESS-OF · * DEREFERENCE
&x → x의 주소 얻기
*p → p가 가리키는 곳의 값 (역참조)
&x gets the address · *p reads the value it points to.
&x хаягийг авна · *p заасан газрын утгыг уншина.
& = 값 → 주소 · * = 주소 → 값
&: value → address · *: address → value

C로 직접 써 보기
Try it in C · C хэл дээр туршъя
int x = 10;
int *p = &x;          // x의 주소 저장

printf("%d\n", *p);    // 10 · 역참조
*p = 20;               // p를 통해 x 변경
printf("%d\n", x);     // 20
printf("%zu\n", sizeof(p)); // 8 (64비트)
① *p = 20은 p가 아니라 x를 바꿈
EN: Writing *p changes x · MN: *p-д бичвэл x өөрчлөгдөнө
② 포인터 타입(int *)은 가리키는 값의 타입을 알려 줌
EN: Type tells what it points to · MN: Төрөл нь юуг заахыг хэлнэ
③ 포인터 크기는 타입과 무관, 64비트에선 보통 8바이트
EN: Usually 8 bytes on 64-bit · MN: 64 битэд ихэвчлэн 8 байт
