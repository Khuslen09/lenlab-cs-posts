Definition · Тодорхойлолт
SUPERVISED · 지도 학습
입력과 정답(라벨)을 함께 주고 규칙을 학습
Learns from inputs paired with correct labels.
Оролт ба зөв хариулт (шошго)-оос суралцана.
UNSUPERVISED · 비지도 학습
정답 없이 데이터 속 구조·패턴을 스스로 찾음
Finds structure in data without labels.
Шошгогүй өгөгдлөөс бүтэц, хэв маягийг олно.
REINFORCEMENT · 강화 학습
행동하고 받은 보상을 최대화하도록 학습
An agent learns actions that maximize reward.
Агент шагналаа хамгийн их болгох үйлдэлд суралцана.
핵심 차이 = 무엇으로 배우나 (정답 · 없음 · 보상)
What it learns from: labels · nothing · rewards

Supervised vs unsupervised in code · Кодоор харьцуулах
X = [[1], [2], [9], [10]]  # 공부 시간
y = [0, 0, 1, 1]           # 라벨: 불합격/합격

sup = DecisionTreeClassifier().fit(X, y)
print(sup.predict([[8]]))   # [1]

uns = KMeans(n_clusters=2, n_init=10).fit(X)
print(uns.labels_)          # 예: [0 0 1 1]
① 지도 학습은 fit(X, y) — 정답 y가 필요
EN: Supervised needs labels y · MN: Шошго y хэрэгтэй
② 비지도 학습은 fit(X) — X만으로 그룹을 나눔
EN: Unsupervised groups X alone · MN: Зөвхөн X-ээр бүлэглэнэ
③ 군집 번호(0·1)는 임의 — 의미는 사람이 해석
EN: Cluster IDs are arbitrary · MN: Кластерын дугаар санамсаргүй
