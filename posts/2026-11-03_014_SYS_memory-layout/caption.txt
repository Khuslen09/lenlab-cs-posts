🇺🇸 Is my variable on the heap or the stack?
⠀
Program memory has four areas: Code (instructions), Data (global and static variables), Heap (dynamic allocation) and Stack (local variables and parameters).
You allocate and free heap memory yourself with malloc or new, while stack memory disappears automatically when the function returns.
⠀
👉 The pointer p lives on the stack, but the malloc block it points to lives on the heap! The heap grows up, the stack grows down.
⠀
⠀
🇲🇳 Миний хувьсагч heap-д үү, stack-д үү?
⠀
Програмын санах ой Code (машин код), Data (глобал ба static хувьсагч), Heap (динамик хуваарилалт), Stack (локал хувьсагч, параметр) гэсэн 4 хэсэгтэй.
Heap-ийг malloc·new-ээр авч өөрөө чөлөөлдөг бол stack функц дуусахад автоматаар устдаг.
⠀
👉 p заагч өөрөө stack-д, түүний заасан malloc хэсэг heap-д байна! Heap дээшээ, stack доошоо өсдөг.
