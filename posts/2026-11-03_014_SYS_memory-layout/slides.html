C 코드로 찾아보기
Where does each live? · Хаана хадгалагдах вэ?
int g = 10;                // Data
int main(void) {           // Code
    int x = 20;            // Stack
    int *p = malloc(sizeof(int));
                           // *p → Heap
    *p = x + g;
    free(p);  // 직접 해제 · free it
    return 0;
}
① 포인터 p 자체는 스택, p가 가리키는 값이 힙
EN: p → stack, *p → heap · MN: p нь stack-д, *p нь heap-д
② x는 main이 끝나면 자동으로 사라짐
EN: x is freed automatically · MN: x автоматаар устна
③ free를 빼먹으면 메모리 누수
EN: Memory leak · MN: Санах ойн алдагдал
