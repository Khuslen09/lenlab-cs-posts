C로 비교해 보기
Compare in C · C хэл дээр харьцуулах
int arr[3] = {10, 20, 30};
printf("%d", arr[2]);     // 30 · 바로 접근

struct Node { int data; struct Node *next; };
struct Node c = {30, NULL}, b = {20, &c}, a = {10, &b};
struct Node *p = &a;          // head
while (p != NULL) {
  printf("%d ", p->data);   // 10 20 30
  p = p->next;
}
① arr[2] = 시작 주소 + 2 × 4바이트 → 계산 한 번, O(1)
EN: Address is computed directly · MN: Хаягийг шууд тооцоолно
② 리스트는 head부터 next를 따라감 → k번째는 O(n)
EN: Walk from the head · MN: Эхнээс нь дагаж явна
③ 노드마다 next 포인터 공간이 더 필요
EN: Extra memory per node · MN: Зангилаа бүрт заагчийн зай нэмэгдэнэ
