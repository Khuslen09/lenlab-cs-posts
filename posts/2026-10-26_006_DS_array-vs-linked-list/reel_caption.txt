🇰🇷 배열 vs 연결 리스트, 언제 뭘 써? 🏢
배열 = 아파트 호수(인덱스로 바로), 리스트 = 보물찾기 쪽지(따라가기).
👉 조회는 배열 O(1), 리스트 삽입·삭제 O(1)은 위치를 알 때만!

🇺🇸 Array vs linked list — when to use which? 🏢
Array = apartment numbers (jump straight in); list = a treasure hunt (follow the notes).
👉 Lookup is O(1) for arrays; list insert/delete is O(1) only if you already know the spot!

🇲🇳 Массив ба холбоост жагсаалт — хэзээ алийг нь ашиглах вэ? 🏢
Массив = орон сууцны дугаар (индексээр шууд), жагсаалт = эрдэнэ хайх тэмдэглэл (дараалан дагах).
👉 Хандалт: массив O(1); жагсаалтын оруулах·устгах O(1) нь байрлалаа мэдэж байвал л!
