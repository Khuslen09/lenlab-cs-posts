Definition · Тодорхойлолт
RASTER · 래스터 · РАСТЕР
픽셀(점)의 격자로 만든 이미지. 픽셀마다 색 값을 저장
An image made of a grid of pixels, each storing a color.
Пиксел бүр өнгөө хадгалдаг пикселийн торон зураг.
VECTOR · 벡터 · ВЕКТОР
점·선·곡선 같은 도형을 수학식(좌표)으로 표현한 이미지
An image described by shapes — points, lines, curves — using math.
Цэг, шугам, муруйг математик томьёогоор дүрсэлсэн зураг.
래스터 = 픽셀을 저장 · 벡터 = 그리는 법을 저장
Raster stores pixels · Vector stores how to draw

01  해상도 의존 · Resolution
래스터는 픽셀 수가 고정, 벡터는 크기와 무관
Растер пикселийн тоонд хамааралтай, вектор хамааралгүй
02  화면은 결국 픽셀 · Rasterization
벡터도 모니터에 보일 땐 래스터화되어 픽셀로 변환
Вектор ч дэлгэц дээр пиксел болж харагдана
03  용도 · Use cases
사진 = 래스터 / 로고·아이콘·폰트 = 벡터

04  파일 형식 · Formats
PNG·JPEG·GIF·BMP = 래스터 / SVG·AI·EPS = 벡터
PNG, JPEG нь растер · SVG нь вектор формат
