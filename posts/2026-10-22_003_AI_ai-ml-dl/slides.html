규칙 vs 학습 (Python)
Rules vs learning · Дүрэм ба суралцах
# 규칙 기반: 사람이 기준을 직접 씀
def rule(temp): return temp > 30

# 머신러닝: 데이터에서 기준을 학습
data = [(22,0), (25,0), (28,0), (31,1), (33,1), (36,1)]
best = max(range(20, 40), key=lambda t:
           sum((x > t) == y for x, y in data))
print(best)  # 28
① 규칙 기반: 사람이 정한 30을 그대로 사용
EN: Human writes the rule · MN: Дүрмийг хүн бичнэ
② 머신러닝: 데이터를 가장 잘 맞히는 기준값을 찾음
EN: Learns the threshold from data · MN: Босгыг өгөгдлөөс сурна
③ 딥러닝: 이 과정을 신경망의 수많은 가중치로 수행
EN: Learns many network weights · MN: Олон жинг сурна
