Python으로 손실 계산
Computing loss in Python · Python-оор алдагдал тооцох
import math
y, p = [3.0, 5.0], [2.5, 5.5]  # 정답, 예측
mse = sum((a-b)**2 for a, b in zip(y, p)) / len(y)
print(mse)                     # 0.25

for q in [0.9, 0.5, 0.1]:      # 정답 확률
    print(round(-math.log(q), 3))
# 0.105  0.693  2.303
① MSE: 오차를 제곱해 평균 → 큰 오차에 더 큰 벌점
EN: Squares the errors · MN: Том алдааг илүү шийтгэнэ
② 교차 엔트로피: −log(정답 확률)
EN: Cross-entropy = −log(p) · MN: Кросс энтропи = −log(p)
③ 정답 확률이 낮을수록 손실이 급격히 커짐
EN: Low p → loss shoots up · MN: p бага бол алдагдал огцом өснө
