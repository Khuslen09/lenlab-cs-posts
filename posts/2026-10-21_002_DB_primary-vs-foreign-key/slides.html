Definition · Тодорхойлолт
PRIMARY KEY · 기본키 · PK
테이블의 각 행을 하나로 식별하는 키. 중복 X · NULL X
Uniquely identifies each row. No duplicates, no NULL.
Мөр бүрийг давхцалгүй ялгаж таних түлхүүр.
FOREIGN KEY · 외래키 · FK
다른 테이블의 기본키를 참조해 두 테이블을 연결하는 키
References another table's primary key to link tables.
Өөр хүснэгтийн үндсэн түлхүүрийг заан холбодог түлхүүр.
기본키 = 식별 · 외래키 = 연결
PK identifies · FK connects

SQL로 키 만들기
Keys in SQL · SQL-д түлхүүр тодорхойлох
CREATE TABLE student (
  stu_id  INT PRIMARY KEY,
  name    TEXT,
  dept_id INT REFERENCES dept(dept_id)
);
INSERT INTO student
  VALUES (2, 'Min', 99);
-- 오류: 99번 학과 없음 · FK error
① PRIMARY KEY: 같은 stu_id 다시 넣으면 거부
EN: Duplicate PK is rejected · MN: Давхардсан PK-г хүлээж авахгүй
② REFERENCES: dept에 없는 값은 거부
EN: Value must exist in dept · MN: dept-д байхгүй утгыг хүлээж авахгүй
③ SQLite는 PRAGMA foreign_keys=ON 필요
EN: SQLite needs FK checks turned on · MN: SQLite-д FK шалгалтыг асаана

여기서 꼭 헷갈린다
Check points · Анхаарах зүйлс
01  개체 무결성 · Entity Integrity
기본키는 NULL · 중복 불가 (NOT NULL + UNIQUE)
Үндсэн түлхүүр хоосон (NULL) ба давхардсан байж болохгүй
02  외래키는 중복 OK · 1 : N
한 학과(10)에 학생 여러 명 → 같은 값 반복 가능
Нэг тэнхимд олон оюутан — FK утга давхцаж болно
03  참조 무결성 · Referential Integrity
참조되는 행은 함부로 삭제 X → ON DELETE 옵션
Заагдаж буй мөрийг шууд устгахгүй — ON DELETE тохиргоо
04  기본키 ≠ 컬럼 1개 · Composite Key
여러 컬럼을 묶은 복합키도 기본키 1개
Хэд хэдэн баганаас бүрдсэн нийлмэл түлхүүр ч нэг PK
