입력 크기 n이 커질 때 연산 횟수가 늘어나는 증가율의 상한

Python으로 세어 보기
Counting steps in Python · Python-д алхам тоолох
def first(a):      # O(1)
    return a[0]

def total(a):      # O(n)
    s = 0
    for x in a: s += x
    return s

def pairs(a):      # O(n²)
    return [(x, y) for x in a for y in a]
① 리스트가 길어져도 한 번에 → O(1)
EN: Same cost for any size · MN: Хэмжээнээс үл хамааран нэг алхам
② 반복문 1개 = n번 → O(n)
EN: One loop runs n times · MN: Нэг давталт n удаа
③ 중첩 반복 n × n → n=1000이면 100만 쌍
EN: n=1000 gives 1,000,000 pairs · MN: n=1000 бол 1 сая хос
